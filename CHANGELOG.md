# Changelog

## 0.1.0

First release of WowUp.rs, a GPL-3.0 Rust port of WowUp 2.24.1 for the terminal.

- Terminal UI with My Addons, Get Addons and Options, plus the `wowup` command line.
- Providers: WowUp Hub, GitHub, WowInterface, TukUI, direct .zip; CurseForge and Wago with your own API keys.
- Scan, sync, install, update, reinstall, remove (with dependencies), ignore, auto update, channels, provider switching.
- Import/export, WTF backups and explorer, in-game update notifications data addon.
- WowUp's 13 languages, launch at login with background auto-updates, `wowup://` and `curseforge://` links.
- No ads, no telemetry.
